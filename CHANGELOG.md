# Change Log
All notable changes to this project will be documented in this file.
This project adheres to [Semantic Versioning](http://semver.org/).

## 3.0.0 - 2026-01-23
- :new: `webp` argument for adding webp versions of your files
- Updated to latest imagemin, updated to remove use of require

## 2.0.0 - 2020-06-12
- :new: `imagemin-newer` is no longer a plugin, but rather a wrapper around `imagemin`
- Bumped `imagemin` to `v7.0.1`

## 1.0.2 - 2016-07-14
- Bump imagemin to `^4.0.0`

## 1.0.1 - 2015-03-27
- Fix documentation

## 1.0.0 - 2015-03-27
- Initial release
